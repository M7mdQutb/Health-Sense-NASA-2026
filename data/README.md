# data/ — sample datasets (contract section ك)
Loaders in `js/core.js` look for these files; if one is missing they return **simulated** data and mark the source as `simulated`.

| File | Source id | What to put in it |
|---|---|---|
| `bidmc_sample.csv` | `physionet-bidmc` | columns `hr,resp,spo2`, 1 Hz, a few hundred rows from PhysioNet BIDMC |
| `osdr_i4.csv` | `osdr-i4` | small summary export from OSDR Inspiration4 (cardio) |
| `osdr_1018.csv` | `osdr-osd-1018` | small summary export from OSDR OSD-1018 (sleep / isolation) |

Download them manually and keep them small. Nothing is fetched from the internet at runtime.
Until then everything shown in the UI is **simulated**.
`body_data.js` is generated by `python tools/build_models.py` — do not edit by hand.
